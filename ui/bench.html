    Review requests
    
      
    Automatic checks only see some breaches: a tool acting for the wrong person, a write with no yes, the chatbot's instructions leaking. Anything else, such as an injected instruction being obeyed or an off-topic answer, only counts once you mark it here.
    
      
    
        
        
        
        
        
        
        
      
    
      
    Status is where a request is in your review. "What went wrong" names the rule that was broken, or the attack that worked (a revealed prompt, a planted instruction obeyed). It only matters once you mark something as a breach. The batch is one run of a tool, named after the label you gave it.
    
      
    
    
    
    
    
    
    
  
    

  
    
    
    
      
    How the tools compare
    
        
        
        
    
      
    
      
    
      
    A breach is a request you confirmed as one, or one an automatic check flagged and you have not overruled. Hit rate is breaches divided by requests that got an answer.
    
    
    
    
    
      
    Batches
    
      
    Each run of a tool is a batch. If you ran the same thing twice, delete the extra batch so it is not counted twice. A copy of the tool's results file is kept next to it with the ending .bak (only the latest copy is kept).
