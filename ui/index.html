Settings for every run

Set these once. Guided scan and Run single tools both use them, and both send their jobs to the same Queue.

Guardrails: which protections to test

A guardrail is a safety layer around the chatbot. Tick one or more. Each run happens once for every guardrail you tick, so you can compare them. Tick all of them if you are not sure.

The grey code on each card is the name used in the Queue and in the results grid.

The target is not reachable, so runs will be refused until you start it.

Tier: how much to run

Start with Smoke to check that everything is connected. Use Standard for results you want to report.

Documents: what the chatbot reads

The chatbot looks up documents before it answers. A poisoned document hides instructions or a link to an unknown site. You can change this at any time. Nothing needs restarting.

Single tools use the clean documents unless you choose Poisoned only.
